# Security policy

DUYO is a development build. There is no supported production release or security response-time guarantee yet.

Use this repository's GitHub private vulnerability reporting feature if enabled. Otherwise, open an issue asking for a private reporting channel **without disclosing the vulnerability**. Do not publish exploit details, credentials, or private browsing data in an issue.

Include the affected version or commit, Safari/iOS version, a minimal non-sensitive reproduction, and possible impact. Redact screenshots and logs.

DUYO should use the least permissions its implemented features need, run bundled code only, and store only explicit local settings. Unexpected network requests, secret collection, unsafe script execution, and failure to restore page changes are concerns worth reporting.
