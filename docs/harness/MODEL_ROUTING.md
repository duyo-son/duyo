# 모델 라우팅

2026-10-27 확인: Claude Code 2.1.267, 인증 상태는 Bedrock/third_party이다.
개인 설정 모델의 최소 호출은 API 400으로 실패했다. 응답은 Claude Code 2.1.280 이상을 요구했다.
설정된 모델 이름이 있다는 사실은 현재 계정에서 사용 가능하다는 증거가 아니다.
전역 CLI 업데이트나 개인 모델 설정 변경은 하지 않았다.

공식 `--model sonnet` 호출은 성공했다. 초기 provider usage는 Bedrock Sonnet 4.5,
후속 세션 init은 claude-sonnet-5로 표시되어 별칭 해석/제공값이 일치하지 않았다.
특정 실제 모델 ID를 검증된 고정값으로 기록하지 않고 호출 성공한 공식 별칭을 사용한다.
프로젝트 `.claude/settings.json`에 `model: sonnet`을 지정해 실패하는 개인 기본값을 이 프로젝트에서만 덮는다.
2026-10-28 공식 `claude --print --model haiku --tools '' --max-turns 1` 최소 호출도 성공했다.
공식 별칭만 사용하며 고정 버전 ID나 실제 절감액은 추정하지 않는다.

- 테스트 실행·성공/실패 집계: 모델 없이 프로젝트 스크립트로 처리한다. 정상 로그를 모델에 통째로 넣지 않는다.
- 단순 공식 문서 사실 확인: researcher는 `model: haiku`. 필요한 범위와 관련 경로만 전달한다.
- 일반 구현·실패 원인 분석·독립 리뷰: 프로젝트 기본 Sonnet을 상속한다.
- 복잡한 Safari 렌더링: 먼저 Sonnet으로 좁혀 조사하며, 고성능 모델은 실제 필요와 사용 가능 여부 확인 후 선택한다.
- 단순 문구 수정에는 별도 에이전트를 호출하지 않는다. 모델 전환·문맥 전달 비용이 절감보다 커질 수 있다.

이 설정은 Claude Code 프로젝트 역할에 적용된다. 현재 Codex 대화 모델을 변경하는 설정은 아니다.
계정 모델 전체 목록과 실제 작업 비용은 미제공이다. 새로운 모델은 최소 호출 성공 후 사용한다.
[공식 모델 설정](https://code.claude.com/docs/en/model-config).
